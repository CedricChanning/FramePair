# FramePair 0.3.6

- Photo cards and grids now use consistent layouts, making filenames, pixel dimensions, aspect ratios, and selection easier to scan. Duplicated entries display the original filename.
- Warnings and information popovers share a consistent layout. Where hover previews are available, you can take a quick look, then click or use the keyboard to keep the details open.
- Fixed the three-photo Merge preview when card height is limited. An outline highlights the slot selected for filling.
- Moved the aspect ratio warning and reset button next to the filename in the Split editor. Fixed an issue where cropped previews covered the drag handle used to reorder the two Split results together.
- Export progress and cancellation now appear in the bottom bar. Estimate and export errors show the cause and let you copy the relevant file paths.
